# HelioBay image assets

Two original concept photographs were generated with the built-in image-generation tool for this project. No stock photography or remote image hotlinks are required.

- `public/images/hero.webp`: a silver unbranded EV connected to a minimalist solar canopy, leafy surroundings, quiet dark space for the hero headline. Optimized to 1920 pixels wide, approximately 286 KB.
- `public/images/station.webp`: a bright solar charging canopy with green-accent chargers, Dhaka-inspired clean architecture, and tropical planting. Optimized to 1400 pixels wide, approximately 238 KB.

The original PNGs and complete generation prompts are preserved in `../output/imagegen/heliobay-concepts-20260902/`. The site uses `next/image` with responsive sizes, useful alternative text, and a non-photographic fallback if loading fails.

These images depict hypothetical stations, not real facilities. Vehicle branding was excluded from the image briefs. The HelioBay icon is an original code-native energy mark composed from the existing Lucide icon system. Social previews reuse the hero concept image with HelioBay metadata.
